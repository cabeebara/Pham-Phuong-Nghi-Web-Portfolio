# Sketchbook Museum Portfolio

An offline-first interactive portfolio for Pham Phuong Nghi.

## Open the website
1. Extract the entire ZIP folder.
2. Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).
3. Internet is only used for the Montserrat web font; if offline, the site falls back to a sans-serif font.

No build tools, server, or installation are required.

## Included
- Sketch-inspired museum landing page with ink outlines and blue watercolor accents (`#72a9e8`).
- Persistent personal identity card, home/back navigation and animated screen transitions.
- Six Past rooms, including a dedicated Models room with two interactive display plinths.
- Present workroom with four highlighted clickable crates mapped to all four projects (including The Ludo King board design), artwork gallery, and the project brief supplied in the design document.
- Future sketchbook with The Humane Chaos and nine Inner Orbits image tiles.
- Original assets retained under `assets/`; each PDF also has a first-page PNG preview for in-gallery display.

## Notes
- The PDF previews are generated from page one so they can be displayed like image files in a browser. Original PDFs are retained beside them.
- Artwork and project imagery are shown as supplied; the architectural environments and interface are drawn in SVG/CSS to match the requested ink-and-watercolor direction.
